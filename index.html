Google Sheets setup — follow these steps

  1. Go to sheets.google.com and create a new spreadsheet named Orizon WC2026.
  2. Create four tabs: users, predictions, results, config.
  3. In the spreadsheet, go to Extensions → Apps Script. Paste the script below, then click Deploy → New deployment → Web App. Set "Who has access" to Anyone.
  4. Copy the deployment URL and paste it into the field below, then click "Save & connect".
  5. In the config tab, add a row: Column A = admin_wallet, Column B = your wallet address (lowercase). This locks the Admin tab to your wallet only.
